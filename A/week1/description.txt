산출물 3가지
  1. 테스트 영상에 차량 검출 + 추적 적용한 결과 영상
  2. 결과를 JSON 파일로 작성
  3. JSON 파일 구조를 설명한 스키마 문서

  *영상 해석:
  각 박스에 나타난 정보는 3가지
    ex) id:3 car 0.57
    1) id: 추적 ID - ByteTrack이 부여한 고유 번호. 같은 차량이면 영상 내내 같은 ID를 유지한다
    2) car: 클래스 (차종) - 코드에서 classes=[2, 5, 7]로 필터링 하였음.
      2 = car (승용차)
      5 = bus (버스)
      7 = truck (트럭)
    3) 0~1 사이의 숫자: 신뢰도(Confidence) -"이 박스가 진짜 차량일 가능성"을 0~1 사이 숫자로 표현한 것. 높을수록 좋음
