## 프로젝트 역할 분담

- **A** (본인): 실영상 인식 파이프라인 - 영상 → 차량별 도로 좌표 시계열 JSON

- **C**: 행동 분석 - JSON 기반 위험 행동 룰 적용, 평가, 보고서

## 2주차 작업 내용 (이번 폴더)

### 한 일
1. **영상 교체**: 호모그래피에 적합한 영상으로 변경 (경부동탄터널 5차로 CCTV)
2. **호모그래피 캘리브레이션**: 픽셀 좌표 ↔ 도로 평면 미터 좌표 변환
   - 4점 수동 캘리브레이션 (y=250 멀리 / y=330 가까이)
   - 5차로 × 3.5m = 17.5m 도로 가로 폭 기준
3. **JSON v1.0 → v1.1 업그레이드**: 모든 더미 필드를 실제값으로 교체
4. **속도 추정**: 위치 시계열 기반 5프레임 슬라이딩 윈도우 평균
5. **차로 ID 산출**: 도로 미터 좌표를 차로 폭(3.5m)으로 나눠 1~5 부여
6. **시각화 영상 생성**: 원본 + BEV(Bird Eye View) 나란히 표시 (Drive 보관)

### 검증 결과 (요약)
- ✅ Unique 차량 41대 검출 (영상 육안 확인과 일치)
- ✅ 차로 분포 1~5 전부 사용, 도로 밖 검출 0건
- ✅ 평균 속도 47 km/h, 최대 80.9 km/h (터널 내 합리적 범위)
- ✅ 위치 범위 1.88~16.60m (도로 가로 폭 0~17.5m 안)

상세 결과는 `validation_report_v1.1.md` 참조.
