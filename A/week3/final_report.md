## 0. 요약 (Executive Summary)

본 보고서는 운전 행동 검출 시스템의 영상 처리 파이프라인(A 모듈) 개발 결과를 종합 정리한다.

**처리 데이터:**
- 실제 환경(CCTV): 한국 도시 도로 영상 5개
- 시뮬레이션(CARLA): 5개 시나리오 영상

**핵심 성과:**
- ✅ **알고리즘 정확성 입증** (CARLA GT 기반): lane_id 99.4~100%, lateral 0.15m, 매칭률 100%
- ✅ **다양한 환경 대응**: 시내 교차로, 정체, 고속도로 등 다양한 도시 도로 처리
- ✅ **표준화된 출력**: JSON v1.1 스키마로 C 모듈에 일관된 데이터 전달

**시스템 한계:**
- 호모그래피 영역 제한 (검출 영역 ~50m)
- OpenCV 차선 검출 한계 (검출률 20~50%)
- 속도 추정 잡음 (오차 6~13 km/h)

## 1. 프로젝트 개요

### 1.1 목표

CCTV 또는 시뮬레이션 영상으로부터 차량의 위치, 속도, 차로를 추출하여 C 모듈(룰 적용)이 위험 운전 행동을 판단할 수 있도록 한다.

### 1.2 시스템 구성

```
영상 입력
    ↓
YOLOv11n (차량 검출)
    ↓
ByteTrack (차량 추적, ID 부여)
    ↓
호모그래피 변환 (픽셀 → 미터)
    ↓
미터 좌표 기반 계산
  - lane_id (차로 번호)
  - lateral_offset_m (차로 중심 이탈)
  - speed_est_mps (추정 속도)
    ↓
JSON v1.1 출력 → C 모듈 입력
```

### 1.3 사용 기술

| 기술 | 용도 | 비고 |
|---|---|---|
| YOLOv11n (Ultralytics) | 차량 검출 | nano 모델, GPU 가속 |
| ByteTrack | 차량 추적 | track_buffer 90, conf 0.15 |
| OpenCV (findHomography) | 호모그래피 캘리브레이션 | 수동 4점 지정 |
| OpenCV (HoughLinesP + DBSCAN) | 차선 검출 | 보조 기능 |
| CARLA Simulator | GT 영상 생성 | Town06, 5차로 |

## 4. CARLA GT 정량 평가 (시스템 정확성 검증)

CARLA는 GT(정답)가 있어 시스템의 **정량 평가**가 가능. 이게 본 프로젝트의 핵심 성과.

### 4.1 종합 평가표

| 영상 | 검출률 | lane 정확도 | lateral 오차 | 속도 오차 |
|---|---|---|---|---|
| normal | 24.3% | 100.0% | 0.15m | 6.48 km/h |
| lane_weaving | 24.2% | 100.0% | 0.17m | 7.87 km/h |
| tailgating | 17.9% | 100.0% | 0.13m | 5.87 km/h |
| sudden_lane_change | 22.5% | 99.9% | 0.24m | 10.91 km/h |
| speeding | 29.7% | 99.4% | 0.15m | 12.91 km/h |

### 4.2 핵심 강점

**1. lane_id 정확도 99.4~100%**

모든 영상에서 거의 완벽한 차로 판단. 호모그래피 + lane 계산 알고리즘의 정확성 입증.

**2. lateral 오차 0.13~0.24m**

차로 폭 3.5m 대비 3.7~6.9% 오차. 매우 정확한 가로 위치 추정.

**3. 매칭률 100% (오검출 0개)**

A가 검출한 모든 차량이 GT와 일치. 가상 차량이나 오검출 전혀 없음.

### 4.3 검출률 한계 분석

**검출률 17.9~29.7%** — 이건 시스템 결함이 아닌 환경적 한계:

1. **호모그래피 영역 제한 (0~50m)**: GT 차량 일부가 영역 밖 (50m+)
2. **차량 등장 시차**: 5대가 0.1~13.6초에 걸쳐 차례로 화면 등장
3. **카메라 뒤쪽 차량**: longitudinal 음수 차량 검출 불가

**의의:** "검출 영역 안"에서는 거의 완벽한 정확도. 영역 확장 시 검출률 개선 가능.

**✅ 시행착오 분석 능력**

### 5.2 한계 및 개선 방향

**⚠️ 차선 검출 (OpenCV 한계)**
- 현재: 검출률 20~50%
- 원인: OpenCV 픽셀 기반의 본질적 한계
- 개선: UFLDv2 등 딥러닝 차선 검출 적용 가능
- 영향: 호모그래피 기반 lane_id로 보완되어 분석에는 큰 영향 없음

**⚠️ 호모그래피 영역 제한**
- 현재: 영상별 20~50m 영역
- 원인: 호모그래피의 원근 변환 비선형성
- 개선: 더 큰 영역 설정 + 도로 곡률 보정
- 영향: 멀리 있는 차량 분석 불가

**⚠️ 속도 추정 잡음**
- 현재: 평균 오차 6~13 km/h
- 원인: YOLO 박스 위치 변동, 호모그래피 외삽 오차
- 개선: Kalman Filter, 더 긴 평활화 윈도우
- 영향: 속도 위반 판단 시 임계값 여유 필요

**⚠️ 카메라 시점 의존성**
- 현재: 비스듬한 각도만 가능 (수직 시점 부적합)
- 원인: YOLO 학습 데이터 분포 + 호모그래피 가정
- 개선: 다양한 시점 학습 데이터 fine-tuning

**⚠️ 수동 캘리브레이션**
- 현재: 영상별 4점 수동 지정 (30분/영상)
- 원인: 도로 환경 다양성
- 개선: 자동 차선 검출 기반 캘리브레이션

## 8. 시행착오 및 학습

### 8.1 시도하고 효과 없었던 것
