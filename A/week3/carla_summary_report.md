# CARLA 시뮬레이션 영상 처리 종합 보고서

**생성일:** 2026-06-02 11:15
**처리 환경:** Google Colab + YOLOv11n + ByteTrack + OpenCV

## 1. 처리 개요

CARLA 시뮬레이터로 생성된 5개 시나리오 영상을 A 시스템(YOLO+ByteTrack+호모그래피)으로 처리하고, B가 제공한 GT(Ground Truth) 데이터와 비교하여 정량 평가하였다.

**CCTV 처리와의 차이점:**
- CCTV: GT 없음, 결과 검증 불가능
- CARLA: GT 있음, 정량 평가 가능 (정확도 측정)

## 2. CARLA 영상 정보

| 항목 | 값 |
|---|---|
| 영상 수 | 5개 (normal, lane_weaving, tailgating, sudden_lane_change, speeding) |
| 해상도 | 1920×1080 |
| FPS | 30 |

| 차량 수 | 5대 (시나리오마다 동일) |

## 3. 시나리오별 설명

| 시나리오 | 설명 |
|---|---|
| normal | 정상 주행 (대조군) - 모든 차량 정상 속도와 차로 유지 |
| lane_weaving | 차선 표류 - 한 차량이 좌우로 흔들면서 주행 |
| tailgating | 짧은 차간거리 - 한 차량이 앞차에 너무 가깝게 따라감 |
| sudden_lane_change | 급차선 변경 - 한 차량이 빠르게 차로 변경 |
| speeding | 속도 위반 - 한 차량이 다른 차량 대비 50%+ 빠름 |

## 4. 호모그래피 설정

5개 영상 모두 동일한 카메라 위치로, **호모그래피 1번만 캘리브레이션**하여 5개 영상에 공통 적용.

### 4점 좌표

| 점 | 픽셀 (x, y) | 미터 (x, y) |
|---|---|---|
| P1 (멀리 왼쪽) | (860, 560) | (0.0, 50.0) |
| P2 (멀리 오른쪽) | (1085, 560) | (17.5, 50.0) |
| P3 (가까이 오른쪽) | (1500, 1080) | (17.5, 0.0) |
| P4 (가까이 왼쪽) | (530, 1080) | (0.0, 0.0) |

**호모그래피 영역:** 17.5m × 50.0m

### 좌표계 변환 공식 (A → B GT)

- `A_x = B_lateral + 8.75` (anchor lane offset)
- A_y와 B_longitudinal은 비선형 관계로 직접 비교 불가

### 6.2 lane_id 정확도 — 100% 거의 완벽

모든 영상에서 99.4~100%의 lane_id 정확도를 기록.

**의미:** A 시스템이 검출한 차량의 차로 판단이 GT와 거의 완벽하게 일치.
호모그래피 + lane 계산 알고리즘의 정확성 입증.

### 6.3 Lateral 오차 — 0.13~0.24m (매우 정확)

### 6.4 검출률 분석 — 17.9~29.7%

**프레임당 평균 검출률:** 24% (GT 5대 중 평균 1.2대 검출)

**중요 — 검출률 낮은 원인:**
1. **호모그래피 영역 제한**: 분석 영역 0~50m, GT 차량 일부가 영역 밖(50m+)
2. **차량 등장 시차**: 5대 차량이 0.1~13.6초에 걸쳐 차례로 화면 등장
3. **호모그래피 영역 밖 차량**: 음수 longitudinal 차량(카메라 뒤쪽) 검출 불가

**짚을 점:**
- **매칭률 100%**: A가 검출한 모든 차량이 GT와 일치 (오검출 0)
- **검출 가능 영역 내에서는 거의 완벽** (lane 100%, lateral 0.15m)
- 시스템 알고리즘이 아닌 영역 제한이 원인

|---|---|---|---|
| normal | 6.48 km/h | 32.46 km/h |  |

| tailgating | 5.87 km/h | 32.66 km/h |  |

| speeding | 12.91 km/h | 48.88 km/h | 속도 위반 차량 포함 |

**속도 오차 원인:**
- YOLO 박스 위치 변동 (1~2 픽셀 → 미터 변환 시 0.5~1m 오차)
- 호모그래피 외삽 영역에서 오차 ↑
- 추적 ID switching 시 위치 점프
- 5프레임 이동 평균 사용에도 잔존 노이즈

**평가:** 목표 속도 50km/h 대비 12~26% 오차. 양호한 수준이나 개선 여지 있음.

## 7. 시스템 강점과 한계

### 7.1 강점

- ✅ **매칭 정확도 100%**: 검출한 차량 1276개(normal) 모두 GT와 일치, 오검출 0개
- ✅ **lane_id 100%**: 차로 판단 거의 완벽 (모든 영상 99.4%+)
- ✅ **lateral 정확도 95%+**: 차로 폭 대비 4~7% 오차로 매우 정확
- ✅ **다양한 시나리오 대응**: 정상, 표류, 차간거리, 변경, 속도위반 모두 처리

### 7.2 한계

- ⚠️ **검출률 24%**: 호모그래피 영역(0~50m) 제한으로 GT 차량 일부만 검출
  - 원인: 차량들이 영상 길이(35초) 동안 영역 통과
  - 개선 방향: 더 큰 호모그래피 영역, 또는 더 큰 YOLO 모델

- ⚠️ **속도 오차 6~13 km/h**: 추정 속도가 잡음 영향
  - 원인: 박스 위치 변동, 호모그래피 외삽 오차
  - 개선 방향: Kalman Filter 등 시계열 평활화

- ⚠️ **CARLA 차량 특성**: YOLO 학습 데이터(실제 차량)와 약간 다른 모양
  - 결과: conf 0.15 사용해도 작은 차량 검출 어려움
  - 개선 방향: CARLA 데이터로 fine-tuning

## 8. CCTV vs CARLA 처리 비교

| 항목 | CCTV (5개) | CARLA (5개) |
|---|---|---|
| 호모그래피 | 영상별 (5번) | 1번 (공통) |
| GT 데이터 | 없음 | 있음 |
| 정량 평가 | 불가 | 가능 |
| 검출 시간 | 영상별 ~30분 (수동 4점) | 1번 + 영상별 1분 |
| 오검출 | 26~73% (다른 도로 차량) | 0% |
| 환경 다양성 | 높음 (실제 도로) | 통제됨 (시뮬레이션) |
| lane_id 정확도 | 측정 불가 | 99.4~100% |

**의의:** CARLA로 측정한 결과가 시스템의 정확한 평가. CCTV에서의 "도로 밖 검출"은 다른 도로 차량 검출에 의한 것이며, CARLA처럼 통제된 환경에서는 발생하지 않음.

## 10. 결론

CARLA 시뮬레이션 환경에서의 A 시스템 평가 결과:

**알고리즘 정확성 입증 (검출 가능 영역 내):**
- lane_id 정확도 99.4~100%
- lateral 오차 평균 0.15m (차로 폭의 4.4%)
- 매칭 정확도 100% (오검출 0개)

**한계 인식 및 개선 방향:**
- 검출 영역 확장 필요 (현재 0~50m)
- 속도 추정 정밀화 (Kalman Filter 등)
- CARLA 데이터 fine-tuning 시 검출률 개선 기대

**CCTV + CARLA 통합 시사점:**
- 실제 환경(CCTV)에서는 다양한 차량/환경 대응 검증
- 시뮬레이션(CARLA)에서는 알고리즘 정확성 정량 검증
- 두 환경의 결과가 상호 보완적
