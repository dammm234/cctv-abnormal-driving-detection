## 한 줄 요약
weaving 메트릭이 CARLA에서 단조 증가 검증을 통과했고, 실제 CCTV 41대 중 14대를 의심 차량으로 추려냄. abrupt는 실제 영상의 YOLO 노이즈로 신뢰도가 낮아 한계로 명시.

## 결정 사항 (멘토 피드백 반영)
- **좌표계 통합**: 제외 (C는 절대좌표 비교 안 함, 영향 없음)
- **차선 검출**: **제외 확정**. weaving/abrupt는 lateral_offset만으로 동작하므로 C 모듈에 영향 없음.

## 메트릭 2종
| 메트릭 | 측정 | 데이터 |
|---|---|---|
| weaving (차선 흔들림) | lateral_offset 표준편차 | position만 필요 |
| abrupt (급가감속) | 가속도 표준편차 | speed 필요 |

## 단계 1 — B 시나리오 검증 (ground truth)
weaving 단조 증가 통과:
- normal 0.16 / wobble_mild 0.605 / wobble_medium 0.926 / wobble_strong 1.287 ✅
- 정상주행이 이상행동보다 명확히 낮음 ✅

## 단계 2 — A 실제 CCTV 적용
- 분석: 32대 (10프레임 이상 트랙) / 전체 41대
- weaving 임계값 0.30 초과 = **의심 14대**
- 상위: ID 44(1.46), 29(1.41), 39(1.29), 21(1.13), 19·41(1.01)

## 알아낸 한계 (정직한 발견)
1. **abrupt는 실제 CCTV에서 신뢰 어려움**: A의 abrupt 점수(30~70)가 B(5~7)의 10배.
   원인은 YOLO 검출 위치 떨림 → 속도가 인위적으로 들쭉날쭉. 스무딩으로도 B/A 격차 못 메움.
   → 실제 환경에선 **weaving이 주력 지표**, abrupt는 보조/참고로 격하.
2. **임계값은 데이터 출처별로 따로**: CARLA(ground truth)와 실제 CCTV는 노이즈 특성이 달라
   B에서 튜닝한 임계값을 A에 그대로 못 씀. → 가이드 문서의 한계 항목과 일치.
3. **짧은 트랙 주의**: 20프레임 미만 트랙은 노이즈로 점수가 튐. 10프레임 미만은 분석 제외함.

## 남은 작업 (단계 3)
- precision/recall: A에 실제 음주/졸음 정답 라벨이 없어 직접 산출 불가.
  → B의 ground truth로 대체 평가하거나, 의심 14대를 사람이 영상 확인해 정성 검증.
- jerk 메트릭: B README 요청 항목이나 노이즈 민감. 시간 여유 시 보완.
